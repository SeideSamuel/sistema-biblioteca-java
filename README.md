# 📚 Sistema de Gerenciamento de Biblioteca

Projeto desenvolvido em **Java** com o objetivo de praticar os principais conceitos de **Programação Orientada a Objetos (POO)**.

O sistema simula o gerenciamento de uma biblioteca através de um menu interativo no terminal, permitindo cadastrar livros e usuários, realizar empréstimos e devoluções, além de consultar as informações armazenadas.

---

## 🚀 Funcionalidades

- 📖 Cadastro de livros
- 👤 Cadastro de usuários
- 📚 Empréstimo de livros
- 🔄 Devolução de livros
- 🔍 Busca de livros por título
- 🔍 Busca de usuários por CPF
- 📋 Listagem de todos os livros cadastrados
- 👥 Listagem de todos os usuários cadastrados
- 🔠 Ordenação automática dos livros por título
- ✅ Validação para impedir cadastro de livros duplicados
- ✅ Validação para impedir cadastro de usuários com CPF duplicado
- 💻 Interface em modo texto (Console)
